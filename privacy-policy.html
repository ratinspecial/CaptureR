CaptureR By Ratin Motion — Privacy Policy

Last updated: September 25, 2026

CaptureR is a browser extension by Ratin Motion for capturing webpage content and sending the captured package to the user's local RatinSpecial Adobe After Effects workflow or saving it locally as a ZIP file.

Data Collection

CaptureR does not collect, sell, or transfer personal data to external servers. Webpage captures are processed locally in the user's browser.

How Captured Content Is Used

When the user starts a capture, CaptureR may access the webpage content needed to create the requested full-page, visible-area, or custom snip capture.

The captured content is either:

  1. sent to 127.0.0.1:43821, a local bridge running on the user's own computer as part of the RatinSpecial After Effects panel; or
  2. saved locally to the user's Downloads folder as a ZIP file.

Local Preferences

CaptureR uses Chrome's storage API to remember the user's selected destination, such as “Send to After Effects” or “Download ZIP only”. This preference remains local to the browser and is not sent to a remote server.

Remote Code, Analytics and Advertising

CaptureR does not load or execute remotely hosted JavaScript code. All extension JavaScript is included in the extension package.

CaptureR does not use analytics, tracking, or advertising scripts.

Third Parties

CaptureR does not transmit captured webpage content or user data to third-party remote servers. The localhost connection described above is a connection to software running on the user's own computer.

Changes to This Policy

If the extension's data practices change, this policy will be updated accordingly.
